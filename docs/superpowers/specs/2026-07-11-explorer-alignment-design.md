# Explorer 一级目录对齐设计

## 目标

参照用户提供的布局，让桌面端左侧 Explorer 的一级目录展开箭头与“探索”标题左边缘对齐，并缩短“探索”与第一项之间的垂直空隙。

## 已确认的问题

- “探索”标题左边缘位于 Explorer 容器起点。
- 一级目录行同时存在 `2px` 透明左边框和 `4.8px` 左内边距，使展开箭头向右偏移约 `6.8px`。
- Quartz 在根列表开头生成 `.overflow-end` 占位项；它与现有 `5.6px` 的 `.explorer-content` 上边距共同造成过大的顶部空隙。

## 设计方案

采用最小范围的桌面端样式覆盖：

1. 只对根级 `.folder-container` 清除透明左边框和左内边距，使一级目录箭头与“探索”标题共用同一条左对齐线。
2. 将根列表开头的 `.overflow-end` 占位项压缩为零高度，并清除其内外边距。
3. 将 `.explorer-content` 的顶部外边距设为零，保留目录行自身的垂直空间，使标题和第一项之间仍有清晰但紧凑的间隔。
4. 不修改嵌套目录的缩进、当前笔记的蓝色选中背景、颜色、字体或展开动画。
5. 样式限定在宽度大于 `800px` 的桌面布局，避免改变移动端抽屉式 Explorer。

## 影响范围

- 只修改 `quartz/styles/custom.scss`。
- 不修改 Quartz 插件源码。
- 不修改 `content` 中的 Obsidian Markdown 笔记。
- 不处理或提交当前工作区中与本任务无关的 `.gitignore` 修改。

## 验收标准

- 一级目录展开箭头的左坐标与“探索”标题左坐标基本一致，允许小于 `1px` 的渲染误差。
- “探索”按钮底部到第一项目录行顶部的空隙明显缩小，不再出现额外空白占位高度。
- 嵌套笔记仍保持原有层级缩进和选中样式。
- Explorer 展开、折叠在浅色和深色模式下均正常。
- Prettier、Quartz 测试和正式构建全部通过。
