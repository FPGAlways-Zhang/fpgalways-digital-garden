# 搜索结果面板间距与密度设计

## 目标

参考用户提供的图 1，调整当前 Quartz 搜索弹层的垂直层级和左侧结果列表密度。搜索功能、双栏比例和文章预览逻辑保持不变。

## 视觉方案

- 搜索输入框继续位于当前高度，不移动整个搜索区域。
- 搜索结果面板与输入框分离，两者之间增加 `24px` 垂直间距。
- 输入框与结果面板分别使用完整的四角圆角、边框和阴影，使两块区域的层级清晰，但仍保持同一套花园主题颜色。
- 左侧结果项目标高度约为 `50px`。通过缩小上下内边距、统一标题行高实现，不强制截断正常的两行长标题。
- 保留当前结果的淡蓝背景和左侧蓝色选中线。
- 桌面端继续采用约 `40% / 60%` 的结果与预览双栏。

## 响应式与可访问性

- `800px` 以下继续隐藏文章预览，仅显示结果列表。
- 移动端结果面板与输入框之间使用更紧凑的间距，避免挤占有限高度。
- 保留键盘焦点状态以及 `prefers-reduced-motion` 规则。

## 实现范围

只修改 `quartz/styles/custom.scss` 中现有搜索样式覆盖，不修改 Quartz 搜索组件、脚本、插件配置或 Obsidian Markdown 内容。

## 验收标准

1. 桌面端搜索输入框与结果面板之间的实际间距约为 `24px`。
2. 单行搜索结果项的实际高度约为 `50px`，明显低于当前高度。
3. 结果面板四角圆角完整，边框与阴影没有断裂。
4. 双栏宽度仍约为 `40% / 60%`。
5. 浅色、深色和移动端样式均正常。
6. Quartz 测试、格式检查和静态构建通过。
